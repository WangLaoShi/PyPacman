## 第一章：打开一个游戏窗口

**本章目标**：运行代码，弹出一个 1024×768 的游戏窗口。

**涉及 Python 知识**：`import`、`if __name__`、类的基本概念

### 1.1 最简入口

打开 [main.py](../main.py)，只有 3 行有效代码：

```python
from src.runner import GameRun

if __name__ == '__main__':
    gr = GameRun()
    gr.main()
```

**逐行解释**：

```python
from src.runner import GameRun
# ↑ 从 src 包的 runner 模块里，导入 GameRun 这个类
# src 是一个文件夹（里面有 __init__.py）
# runner 是文件夹里的 runner.py 文件
# GameRun 是文件里的一个类

if __name__ == '__main__':
    # ↑ 这行的意思是「只有直接运行 main.py 时才执行下面的代码」
    # 如果 main.py 被其他文件 import，下面的代码不会执行
    gr = GameRun()   # 创建 GameRun 对象（「实例化」）
    gr.main()        # 调用它的 main 方法，进入游戏循环
```

### 1.2 初始化 pygame

打开 [src/runner.py](../src/runner.py)，看 `GameRun.__init__`：

```python
class GameRun:
    def __init__(self):
        pygame.init()                    # 初始化 pygame 引擎
        self.screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
        # ↑ 创建窗口，尺寸来自常量 SCREEN_WIDTH=1024, SCREEN_HEIGHT=768
        pygame.display.set_caption("Py-Pacman")
        # ↑ 设置窗口标题
```

**Python 知识点**：

- **`import`**：使用其他文件里的代码前，必须先导入。
- **类（class）**：`GameRun` 是一个类，像一张「图纸」。`gr = GameRun()` 是按图纸造出的「实物」。
- **`self`**：类的方法里第一个参数 `self` 代表「这个对象自己」。`self.screen` 表示「我的屏幕」。
- **元组（tuple）**：`(SCREEN_WIDTH, SCREEN_HEIGHT)` 是一个元组，圆括号包起来的固定数量的值。

### 1.3 游戏主循环

所有游戏都有一个「永远在转」的主循环：

```python
def main(self):
    clock = pygame.time.Clock()
    dt = None

    while self.game_state.running:       # 只要游戏还在运行
        # 第 1 步：处理事件（键盘、关窗）
        for event in pygame.event.get():
            self.events.handle_events(event)

        # 第 2 步：清屏（涂黑）
        self.screen.fill(Colors.BLACK)

        # 第 3 步：画迷宫和分数
        self.gui.draw_screens()

        # 第 4 步：画精灵（吃豆人、幽灵）
        self.all_sprites.draw(self.screen)

        # 第 5 步：更新精灵状态
        self.all_sprites.update(dt)

        # 第 6 步：把画好的内容显示到屏幕
        pygame.display.flip()

        # 第 7 步：控制帧率（60 FPS）
        dt = clock.tick(self.game_state.fps)
        dt /= 100
```

**Python 知识点**：

- **`while` 循环**：条件为 `True` 时反复执行，直到条件变 `False`。
- **`for` 循环**：遍历事件队列里的每一个事件。
- **布尔值（bool）**：`self.game_state.running` 是 `True` 或 `False`。

## 第三章：画出迷宫墙壁和豆子

**本章目标**：在窗口里画出一个完整的迷宫。

**涉及 Python 知识**：二维列表、`for` 嵌套循环、字典映射函数、`**kwargs`

### 3.1 迷宫的数据结构

迷宫本质上是一个「二维表格」，每个格子里写着一个字符串：

```
wall  wall  wall  wall  wall  ...
wall  dot   dot   dot   wall  ...
wall  dot   wall  dot   wall  ...
wall  power wall  dot   wall  ...
...
```

- `"wall"` → 画蓝色墙壁
- `"dot"` → 画白色小豆子
- `"power"` → 画黄色能量豆
- `"void"` → 什么都不画（空地）
- `"null"` → 同上
- `"elec"` → 画红色电网线

### 3.2 绘制代码

打开 [src/gui/pacman_grid.py](../src/gui/pacman_grid.py)：

```python
class PacmanGrid:
    def __init__(self, screen, game_state):
        # 策略字典：格子类型 → 对应的绘制方法
        self.function_mapper = {
            "void": self.draw_void,
            "wall": self.draw_wall,
            "dot": self.draw_dot,
            "power": self.draw_power,
            "null": self.draw_void,
            "elec": self.draw_elec,
        }

    def draw_level(self):
        curr_x, curr_y = self.start_x, self.start_y

        for _, row in enumerate(self._matrix):       # 遍历每一行
            for _, col in enumerate(row):            # 遍历行里的每一格
                draw_func = self.function_mapper[col]  # 查字典找到画法
                draw_func(x=curr_x, y=curr_y,
                          w=CELL_SIZE[0], h=CELL_SIZE[0])
                curr_x += CELL_SIZE[0]              # 向右移一格

            curr_x = self.start_x                    # 换行时 x 回到起点
            curr_y += CELL_SIZE[0]                   # y 向下移一格
```

### 3.3 具体画法

```python
def draw_wall(self, **kwargs):
    """画墙壁：蓝色实心矩形"""
    draw_rect(kwargs["x"], kwargs["y"],
              kwargs["w"], kwargs["h"],
              self._screen, Colors.WALL_BLUE)

def draw_dot(self, **kwargs):
    """画豆子：5×5 白色小方块"""
    dot_x = kwargs["x"] + kwargs["w"]
    dot_y = kwargs["y"] + kwargs["h"]
    draw_rect(dot_x, dot_y, 5, 5, self._screen, Colors.WHITE)

def draw_power(self, **kwargs):
    """画能量豆：黄色圆"""
    circle_x = kwargs["x"] + kwargs["w"]
    circle_y = kwargs["y"] + kwargs["h"]
    draw_circle(circle_x, circle_y, 7, self._screen, Colors.YELLOW)
```

**Python 知识点**：

- **二维列表**：`matrix[row][col]`，外层是行，内层是列。
- **嵌套 `for` 循环**：外层遍历行，内层遍历列。
- **字典映射函数**：`self.function_mapper[col]` 取出一个方法，然后 `draw_func(...)` 调用它。
- **`**kwargs`**：接收任意数量的「关键字参数」，在函数里变成字典。`draw_wall(x=10, y=20, w=5, h=5)` 里 `kwargs` 就是 `{"x": 10, "y": 20, "w": 5, "h": 5}`。

### 6.1 事件处理循环

打开 [src/game/event_management.py](../src/game/event_management.py)：

```python
class EventHandler:
    def __init__(self, screen, game_state):
        self._screen = screen
        self._game_screen = game_state  # 实际上是 GameState 对象

    def handle_events(self, event):
        """每帧调用，处理所有输入事件"""

        # 点窗口右上角 × 按钮
        if event.type == QUIT:
            self.pygame_quit()

        # 按下键盘
        if event.type == KEYDOWN:
            self.key_bindings(event.key)

    def key_bindings(self, key):
        """把按键翻译成方向字符串"""
        if key == K_LEFT:
            self._game_screen.direction = "l"
        elif key == K_RIGHT:
            self._game_screen.direction = "r"
        elif key == K_UP:
            self._game_screen.direction = "u"
        elif key == K_DOWN:
            self._game_screen.direction = "d"

    def pygame_quit(self):
        self._game_screen.running = False
```

## 第七章：吃豆人移动与撞墙

**本章目标**：吃豆人根据方向移动，遇到墙壁停下。

### 7.1 细网格（tiny_matrix）

为了实现像素级平滑移动和精确碰撞，项目把每个大格子再切成小格子：

```python
# coord_utils.py
def get_tiny_matrix(matrix, cell_size, pacman_speed):
    """把粗地图放大为细分网格"""
    sub_div = cell_size // pacman_speed   # 每格切成 20//4 = 5 小格
    num_rows = len(matrix) * sub_div
    num_cols = len(matrix[0]) * sub_div

    # 创建全 "null" 的细网格
    tiny_matrix = [["null"] * num_cols for _ in range(num_rows)]

    # 把墙复制到细网格
    for row in matrix:
        for cell in row:
            if cell != "wall":
                cell = "null"
            for sx in range(sub_div):
                for sy in range(sub_div):
                    tiny_matrix[tiny_r + sx][tiny_c + sy] = cell
    ...
```

### 7.2 移动与碰撞检测

```python
# pacman.py
def move_pacman(self, dt):
    """每帧移动 PACMAN_SPEED 像素"""
    if self.move_direction == "l":
        # 先检测左边有没有墙
        if self.edges_helper_vertical(self.tiny_start_x, self.tiny_start_y, -1):
            self.rect_x -= PACMAN_SPEED   # 没墙，向左移动
            self.tiny_start_y -= 1        # 细网格列号 -1
    elif self.move_direction == "r":
        if self.edges_helper_vertical(...):
            self.rect_x += PACMAN_SPEED
            self.tiny_start_y += 1
    # 上下同理...

def edges_helper_vertical(self, row, col, additive):
    """检测移动方向上是否有墙"""
    for r in range(self.subdiv * 2):   # 吃豆人占 2 个子格高度
        if self.tiny_matrix[row + r][col + additive] == "wall":
            return False   # 有墙，不能移动
    return True            # 没墙，可以移动
```

```python
def boundary_check(self):
```

- **`while` 循环**：主循环每帧执行一次。
- **布尔逻辑**：`if ... == "wall"` 返回 `True` 或 `False`。
- **整数除法 `//`**：`20 // 4 = 5`（取整）。

```python
def eat_dots(self):
```

## 第九章：幽灵出场

**本章目标**：创建四只幽灵，每只延迟不同时间出鬼屋。

### 9.1 幽灵基类

```python
# ghosts.py
from abc import abstractmethod, ABC

class Ghost(Sprite, ABC):
    """
    幽灵基类：
    - 继承 Sprite：可以被 Group 管理和绘制
    - 继承 ABC：抽象基类，不能直接创建 Ghost 对象
    """
    def __init__(self, name, ghost_matrix_pos, grid_start_pos,
                 matrix, game_state):
        super().__init__()
        self.name = name
        self._dead_wait = GHOST_DELAYS[self.name]  # 查字典获取延迟时间
        self._creation_time = pytime.get_ticks()   # 记录创建时间
        ...

    @abstractmethod
    def determine_target(self):
        """子类必须实现这个方法，否则报错"""
        ...
```

### 9.2 幽灵管理器（工厂）

```python
class GhostManager:
    """创建四只幽灵的工厂"""
    def load_ghosts(self):
        adder = 0
        # 元组列表：(名字, 类)
        ghosts = [('blinky', Blinky),
                  ('pinky', Pinky),
                  ('inky', Inky),
                  ('clyde', Clyde)]

        for ghost_name, ghost in ghosts:
            ghost_pos = (self.ghost_matrix_pos[0],
                         self.ghost_matrix_pos[1] + adder)
            # 创建具体子类对象
            self.ghosts_list.append(ghost(ghost_name, ghost_pos, ...))
            adder += 1  # 下一只鬼换一行
```

### 9.3 延迟出笼

```python
def check_is_released(self):
    """检查是否到了出笼时间"""
    if self._is_released:
        return
    curr_time = pytime.get_ticks()
    # 当前时间 - 创建时间 > 延迟时间 → 出笼
    if (curr_time - self._creation_time) > self._dead_wait:
        self._is_released = True
        # 移到出口位置
        self.rect_x, self.rect_y = self._get_coords_from_idx(
            (11, self._ghost_matrix_pos[1])
        )
```

**Python 知识点**：

- **多重继承**：`class Ghost(Sprite, ABC)` 同时继承两个类。
- **`@abstractmethod`**：标记的方法子类必须实现。
- **工厂模式**：`GhostManager` 负责创建对象，调用者不用关心具体怎么创建。
- **元组解包**：`for ghost_name, ghost in ghosts` 一次取两个值。

```python
        mode = self._game_state.ghost_mode
        if mode == "scatter":

        elif mode == "chase":

class Inky(Ghost):
    def determine_target(self):

            # 利用 Blinky 位置做向量计算
            return self.calculate_inky_target()
```

```python
def get_clyde_random_target(self):
    pacman_rect = self._get_idx_from_coords(...)
    # 曼哈顿距离 = |行差| + |列差|
    dis = abs(pacman_rect[0] - self.curr_pos[0]) + \
          abs(pacman_rect[1] - self.curr_pos[1])

        return self.get_random_target()  # 远：随机走
    return pacman_rect                   # 近：追吃豆人
```

```python
# sounds.py
class SoundManager:
    _instance = None  # 类变量：全局唯一实例

    def __new__(cls, *args, **kwargs):
        # 控制只创建一个对象
        if not cls._instance:
            cls._instance = super().__new__(cls, *args, **kwargs)
        return cls._instance

    def __init__(self):
        # 防止重复初始化
        if not hasattr(self, "_initialized"):
            self._initialized = True
            self._sounds = {}
            self._channels = {}
            pygame.mixer.pre_init()
            pygame.mixer.set_num_channels(64)
```

### 12.2 加载音效

```python
def load_sound(self, name, filepath, volumne=0.5, freq=200, channel=0):
    """
    加载音效
    - name: 逻辑名，如 "dot"
    - filepath: 文件路径
    - volumne: 音量 0~1（默认 0.5）
    - freq: 防抖间隔（毫秒）
    - channel: 通道编号
    """
    self._sounds[name] = {
        "sound": pygame.mixer.Sound(filepath),
        "freq": freq,
        'last_played': 0
    }
    self._sounds[name]['sound'].set_volume(volumne)
    self._channels[name] = pygame.mixer.Channel(channel)
```

```python
# log_handle.py
import logging

def get_logger(name: str, level: int = logging.DEBUG):
    """获取配置好的 Logger"""
    logger = logging.getLogger(name)
    logger.setLevel(level)

    # 同一 name 的 logger 是单例，避免重复添加 handler
    if not logger.hasHandlers():
        console_handler = logging.StreamHandler()
        console_handler.setLevel(level)

        formatter = logging.Formatter(
            '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
        )
        console_handler.setFormatter(formatter)
        logger.addHandler(console_handler)

    return logger
```
