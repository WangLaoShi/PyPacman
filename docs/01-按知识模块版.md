## 1. 变量与基本类型

**一句话**：变量就是给一个值起个名字，Python 里不需要声明类型，直接写。

**四种最基本的类型**：

| 类型 | 含义 | 项目中的例子 |
|------|------|-------------|
| `int` | 整数 | `DOT_POINT = 10`（吃一颗豆得 10 分） |
| `float` | 小数 | `self._t = 0`（幽灵移动的插值进度，0 到 1 之间的小数） |
| `str` | 字符串 | `"scatter"`（幽灵的一种 AI 模式） |
| `bool` | 布尔值 | `self._is_released = False`（幽灵是否已出鬼屋） |

**在哪里看**：[src/configs.py](../src/configs.py) 整个文件都是变量定义。

```python
# src/configs.py 节选
SCREEN_WIDTH = 1024      # int：窗口宽度（像素）
SCREEN_HEIGHT = 768      # int：窗口高度
PACMAN_SPEED = 4         # int：吃豆人每帧走几个像素
DOT_POINT = 10           # int：吃一颗普通豆的得分
```

**小白要点**：
- 变量名全大写（如 `SCREEN_WIDTH`）是 Python 的「常量约定」，意思是「请不要改我」。
- Python 不需要写 `int x = 10`，直接 `x = 10` 就行，解释器自己知道类型。

## 2. 字符串与 f-string

**一句话**：字符串就是文字；f-string 是一种在字符串里嵌入变量的简便写法。

**在哪里看**：
- 普通字符串：[src/game/state_management.py](../src/game/state_management.py) 里的方向值 `"l"` `"r"` `"u"` `"d"`
- f-string：[src/gui/pacman_grid.py](../src/gui/pacman_grid.py) 的 `load_level` 方法

```python
# 普通字符串
self.__direction = ""          # 空字符串，表示「还没按方向键」
if value not in ["r", "l", "u", "d", ""]:  # 字符串列表做白名单
    raise ValueError("Unknown direction")

# f-string：在字符串里直接嵌入变量
level_path = f"levels/level{level_number}.json"
# 如果 level_number = 1，结果就是 "levels/level1.json"
```

**小白要点**：
- `f"..."` 的 `f` 是 format 的缩写，大括号 `{}` 里的内容会被替换成变量的值。
- 不用 f-string 的话，得写 `"levels/level" + str(level_number) + ".json"`，又长又容易出错。

## 3. 元组 tuple

**一句话**：元组是用圆括号包起来的一组固定数量的值，一旦创建就不能改。

**在哪里看**：[src/configs.py](../src/configs.py) 里的颜色和尺寸

```python
# 颜色用 RGB 三元组
WHITE = (255, 255, 255)   # 红=255, 绿=255, 蓝=255 → 白色
BLACK = (0, 0, 0)         # 三个 0 → 黑色
WALL_BLUE = (24, 24, 217) # 一种蓝色

# 尺寸用二元组
CELL_SIZE = (20, 20)      # (宽, 高)，每格 20×20 像素
PACMAN = (32, 32)         # 吃豆人贴图目标尺寸
```

**小白要点**：
- 元组和列表的区别：元组不能改（`t[0] = 1` 会报错），列表可以改。
- 游戏里用元组是因为颜色 `(R,G,B)` 永远三个数，尺寸 `(宽,高)` 永远两个数，不需要增删。
- 解包写法：`x, y = (10, 20)` 可以一行把两个值分别赋给两个变量。

## 4. 列表 list

**一句话**：列表是用方括号包起来的一组可以修改的值。

**在哪里看**：
- 关卡矩阵：[levels/level1.json](../levels/level1.json)（读进来就是列表套列表）
- 动画帧：[src/sprites/sprite_configs.py](../src/sprites/sprite_configs.py)

```python
# 一维列表
self.left_frames = frame_helper("left")  # 3 张 PNG 组成的列表

# 二维列表（列表套列表）—— 关卡矩阵
self._matrix = level_json["matrix"]
# matrix[0] 是第一行，matrix[0][0] 是第一个格子

# 列表的方法
self.ghosts_list = []                    # 空列表
self.ghosts_list.append(ghost)           # 往末尾加一个幽灵
self.all_sprites.empty()                 # 清空（pygame 提供的方法）
```

**小白要点**：
- `list[0]` 取第一个元素（索引从 0 开始，不是 1）。
- `list[-1]` 取最后一个元素（负数索引是 Python 特色）。
- 二维列表 `matrix[row][col]` 就像Excel表格：先行，后列。

## 5. 字典 dict

**一句话**：字典是「键→值」的映射表，用花括号写，通过键来查值。

**在哪里看**：几乎每个文件都有。最典型的是 [src/configs.py](../src/configs.py) 的幽灵参数表和 [src/sprites/sprite_configs.py](../src/sprites/sprite_configs.py) 的贴图路径表。

```python
# 幽灵出笼延迟（秒）
GHOST_DELAYS = {
    "inky": 12000,
    "pinky": 8000,
    "blinky": 4000,
    "clyde": 16000,
    "blue": 0
}
# 用法：GHOST_DELAYS["blinky"] → 4000

# 贴图路径字典（值是列表）
PACMAN_PATHS = {
    "left":  ["assets/pacman-left/1.png", "assets/pacman-left/2.png", ...],
    "right": ["assets/pacman-right/1.png", ...],
    "up":    [...],
    "down":  [...]
}

# 方向映射：单字母 → 帧列表
self.direction_mapper = {
    "l": self.left_frames,
    "r": self.right_frames,
    "u": self.up_frames,
    "d": self.down_frames,
}
```

**小白要点**：
- 字典的键必须是不可变类型（字符串、数字、元组），值可以是任何东西。
- `dict[key]` 如果 key 不存在会报 `KeyError`；`dict.get(key)` 不存在返回 `None`，更安全。
- 字典和列表可以嵌套：`{"blinky": [1, 2, 3]}` 是合法的。

## 6. 条件判断 if / elif / else

**一句话**：根据不同条件执行不同代码。

**在哪里看**：[src/game/event_management.py](../src/game/event_management.py) 处理键盘输入，[src/sprites/ghosts.py](../src/sprites/ghosts.py) 幽灵 AI 分支

```python
# 键盘事件处理（event_management.py）
if event.type == QUIT:
    self.pygame_quit()

if event.type == KEYDOWN:
    self.key_bindings(event.key)

# 方向键绑定（key_bindings 方法内）
if key == K_LEFT:
    self._game_screen.direction = "l"
elif key == K_RIGHT:
    self._game_screen.direction = "r"
elif key == K_UP:
    self._game_screen.direction = "u"
elif key == K_DOWN:
    self._game_screen.direction = "d"

# 幽灵模式分支（ghosts.py Blinky.determine_target）
mode = self._game_state.ghost_mode
if mode == "scatter":
    target = GHOST_SCATTER_TARGETS[self.name]
elif mode == "chase":
    target = self._get_idx_from_coords((pacman_rect[0], pacman_rect[1]))
```

**小白要点**：
- `if` 后面跟的表达式结果必须是 `True` 或 `False`。
- `elif` 是 "else if" 的缩写，可以有任意多个。
- Python 用缩进（4 个空格）表示代码块，不用大括号 `{}`。
- 比较用 `==`，赋值用 `=`，别搞混。

## 7. 循环 for 与 while

**一句话**：`for` 遍历一组东西，`while` 在条件为真时反复执行。

**在哪里看**：
- for：[src/gui/pacman_grid.py](../src/gui/pacman_grid.py) 的 `draw_level` 方法（画迷宫的双重循环）
- while：[src/runner.py](../src/runner.py) 的游戏主循环

```python
# for 循环：遍历迷宫矩阵画格子（pacman_grid.py）
for _, row in enumerate(self._matrix):       # 外层：每一行
    for _, col in enumerate(row):            # 内层：每一列
        draw_func = self.function_mapper[col]
        draw_func(x=curr_x, y=curr_y, w=CELL_SIZE[0], h=CELL_SIZE[0])
        curr_x += CELL_SIZE[0]
    curr_x = self.start_x
    curr_y += CELL_SIZE[0]

# for 循环：统计剩余豆子（pacman.py）
for row in range(len(self.matrix)):
    for col in range(len(self.matrix[0])):
        if self.matrix[row][col] in ['dot', 'power']:
            collectibles += 1

# while 循环：游戏主循环（runner.py）
while self.game_state.running:
    # 处理事件 → 画画面 → 更新精灵 → 刷新显示
    for event in pygame.event.get():
        self.events.handle_events(event)
    self.screen.fill(Colors.BLACK)
    self.gui.draw_screens()
    self.all_sprites.draw(self.screen)
    self.all_sprites.update(dt)
    pygame.display.flip()
    dt = clock.tick(self.game_state.fps)
```

**小白要点**：
- `for x in list` 会依次把列表里每个元素赋给 `x`。
- `range(n)` 生成 `0, 1, 2, ..., n-1`。
- `enumerate(list)` 同时给你索引和值：`for i, item in enumerate(list)`。
- `_` 是「我不需要这个变量」的约定写法。
- `while` 循环一定要有办法让条件变 `False`，否则死循环。

## 8. 函数 function

**一句话**：把一段逻辑打包成一个可以反复调用的「工具」，给它一个名字，传入参数，得到结果。

**在哪里看**：[src/utils/coord_utils.py](../src/utils/coord_utils.py)（坐标换算工具函数集）

```python
# 函数定义
def get_coords_from_idx(pacman_pos, start_x, start_y,
                        cell_w, cell_h, num_rows, num_cols):
    """逻辑格索引 → 屏幕像素坐标"""
    x, y = __get_x_y(pacman_pos, num_rows, num_cols)
    x_coord = start_x + (y * cell_w)
    y_coord = start_y + (x * cell_h)
    return x_coord, y_coord

# 函数调用
x, y = get_coords_from_idx(
    self.pacman_pos,     # 传入出生格坐标
    self.start_pos[0],   # 迷宫左上角 x
    self.start_pos[1],   # 迷宫左上角 y
    CELL_SIZE[0],        # 格子宽
    CELL_SIZE[1],        # 格子高
    len(self.matrix),    # 行数
    len(self.matrix[0])  # 列数
)

# 带默认参数的函数
def draw_rect(x, y, w, h, screen, color, fill=0):
    """画矩形，fill=0 画边框，非 0 填充"""
    draw.rect(screen, color, (x, y, w, h), fill)
```

**小白要点**：
- `def 函数名(参数):` 定义函数。
- `return` 返回结果；没有 `return` 的函数返回 `None`。
- 默认参数（如 `fill=0`）让调用时可以少写参数。
- 函数名见名知义是好习惯：`get_coords_from_idx` 一看就知道是「从索引获取坐标」。

## 9. 模块与包 import

**一句话**：模块就是一个 `.py` 文件，包就是一个含有 `__init__.py` 的文件夹。`import` 用来使用其他模块里的代码。

**在哪里看**：[main.py](../main.py)（入口文件，只有 3 行有效代码）

```python
# main.py
from src.runner import GameRun

if __name__ == '__main__':
    gr = GameRun()
    gr.main()
```

**三种 import 写法**：

```python
# 写法 1：导入整个模块
import pygame
import json
import sys

# 写法 2：从模块导入特定名字
from src.runner import GameRun
from src.configs import CELL_SIZE, PACMAN_SPEED, DOT_POINT

# 写法 3：导入模块里所有公共名字（不推荐，但小项目方便）
from src.configs import *
# 之后可以直接写 SCREEN_WIDTH 而不是 configs.SCREEN_WIDTH
```

**`if __name__ == '__main__'` 是什么意思？**

```python
# 当你在终端执行 python main.py 时，__name__ 的值是 '__main__'
# 当 main.py 被其他文件 import 时，__name__ 的值是 'main'
# 所以这行代码的意思是：「只有直接运行本文件时，才执行下面的代码」
if __name__ == '__main__':
    gr = GameRun()
    gr.main()
```

**小白要点**：
- `src/` 是一个包（里面有 `__init__.py`），`src.runner` 是包里的模块。
- `from src.runner import GameRun` 只把 `GameRun` 这个名字拿进来，写代码时直接写 `GameRun` 而不是 `src.runner.GameRun`。
- `from configs import *` 省事但 IDE 补全弱，大项目不推荐。

## 10. 类与对象 class

**一句话**：类是「图纸」，对象是「按图纸造出来的实物」。类定义有哪些数据和行为，对象是运行时具体的那份实例。

**在哪里看**：[src/game/state_management.py](../src/game/state_management.py)（`GameState` 类）

```python
class GameState:
    def __init__(self):
        # __init__ 是构造方法，创建对象时自动调用
        # self 代表「这个对象自己」
        self.__level = 1           # 当前关卡
        self.__running = True      # 游戏是否在运行
        self.__fps = 60            # 帧率
        self.__direction = ""      # 玩家按的方向
        self._points = -DOT_POINT  # 当前分数

# 创建对象（实例化）
game_state = GameState()
# 访问属性
print(game_state.level)    # 通过 @property 访问（见第 12 节）
game_state.direction = "l" # 通过 setter 修改
```

**再看一个更直观的类**：[src/sounds.py](../src/sounds.py)

```python
class SoundManager:
    def __init__(self):
        self._sounds = {}        # 字典：音效名 → 音效对象
        self._channels = {}      # 字典：音效名 → 播放通道
        self._background_music = None

    def load_sound(self, name, filepath, volumne=0.5):
        """加载一个音效"""
        self._sounds[name] = {
            "sound": pygame.mixer.Sound(filepath),
            "freq": 200,
            'last_played': 0
        }
        self._sounds[name]['sound'].set_volume(volumne)

    def play_sound(self, name):
        """播放指定名字的音效"""
        if name in self._sounds:
            self._channels[name].play(self._sounds[name]['sound'])
```

**小白要点**：
- `class 类名:` 定义类，类名通常用大写开头（`GameState`、`SoundManager`）。
- `__init__` 是构造方法，`GameState()` 时自动执行。
- `self.xxx` 是对象的属性，每个对象有自己独立的一份。
- 类里的函数叫「方法」，第一个参数必须是 `self`。

## 11. 继承 inheritance

**一句话**：子类可以继承父类的所有属性和方法，然后加上自己的特殊行为。

**在哪里看**：[src/sprites/pacman.py](../src/sprites/pacman.py) 和 [src/sprites/ghosts.py](../src/sprites/ghosts.py)

```python
# 吃豆人继承 pygame 的 Sprite 基类
from pygame.sprite import Sprite

class Pacman(Sprite):
    def __init__(self, screen, game_state, matrix, pacman_pos, start_pos):
        super().__init__()  # 先调用父类 Sprite 的初始化
        # 然后设置 Pacman 自己的属性
        self.screen = screen
        self.game_state = game_state
        ...

    def update(self, dt):
        # Sprite 约定：每帧由 Group.update() 调用
        self.frame_update()
        self.movement_bind()
        self.move_pacman(dt)
        ...
```

```python
# 幽灵基类 Ghost 同时继承 Sprite 和 ABC
class Ghost(Sprite, ABC):
    def __init__(self, name, ...):
        super().__init__()
        self.name = name
        ...

    @abstractmethod
    def determine_target(self):
        """子类必须实现这个方法"""
        ...

# 四个幽灵子类，各自实现不同的追逐策略
class Blinky(Ghost):
    def determine_target(self):
        # 红鬼：直接追 Pac-Man 脚下
        ...

class Pinky(Ghost):
    def determine_target(self):
        # 粉鬼：瞄 Pac-Man 前方 4 格
        ...

class Inky(Ghost):
    def determine_target(self):
        # 青鬼：向量镜像（最复杂）
        ...

class Clyde(Ghost):
    def determine_target(self):
        # 橙鬼：远时随机，近时追
        ...
```

**小白要点**：
- `class 子类(父类):` 表示继承。
- `super().__init__()` 调用父类的构造方法，别忘了这一行，否则父类的初始化不会执行。
- 继承的好处：`Pacman` 自动拥有 `Sprite` 的 `image`、`rect` 属性和被 `Group.draw()` 绘制的能力，不用自己写。
- Python 支持多重继承（`Ghost(Sprite, ABC)`），但一般不推荐滥用。

## 12. 属性封装 @property

**一句话**：`@property` 让一个方法看起来像属性一样访问，可以在「读」和「写」的时候偷偷加入校验逻辑。

**在哪里看**：[src/game/state_management.py](../src/game/state_management.py)（大量使用 `@property`）

```python
class GameState:
    def __init__(self):
        self._points = -DOT_POINT  # 内部字段，单下划线表示「别直接碰」
        self.__direction = ""       # 双下划线，更严格的「私有」

    # ---- 分数属性 ----
    @property
    def points(self):
        """读分数：game_state.points"""
        return self._points

    @points.setter
    def points(self, val):
        """写分数：game_state.points = 100"""
        self._points = val

    # ---- 方向属性（带校验）----
    @property
    def direction(self):
        return self.__direction

    @direction.setter
    def direction(self, value):
        # 写入前校验：只允许这几个值
        if value not in ["r", "l", "u", "d", ""]:
            raise ValueError("Unknown direction")
        self.__direction = value

    # ---- 幽灵模式属性（带校验）----
    @property
    def ghost_mode(self):
        return self._ghost_mode

    @ghost_mode.setter
    def ghost_mode(self, value):
        if value not in ['scatter', 'chase', 'scared']:
            raise ValueError("Only scatter, scared or chase modes are available")
        self._ghost_mode = value
```

**使用效果**：

```python
game_state = GameState()

# 看起来像直接访问属性，实际上走了 getter 方法
print(game_state.points)      # → -10（初始值）

# 看起来像直接赋值，实际上走了 setter 方法（会校验）
game_state.direction = "l"    # OK
game_state.direction = "x"    # 报错 ValueError!
```

**小白要点**：
- `@property` 装饰器让 `game_state.points` 不用加括号，像访问变量一样。
- `@points.setter` 让你在赋值时可以加校验，防止写入非法值。
- `_points` 单下划线 = 「约定私有，请不要直接访问」。
- `__direction` 双下划线 = Python 会做名称改写，更难从外部直接访问。

## 13. 文件读写与 JSON

**一句话**：Python 用 `open()` 打开文件，用 `json` 模块读写 JSON 格式数据。

**在哪里看**：[src/runner.py](../src/runner.py) 读写最高分，[src/gui/pacman_grid.py](../src/gui/pacman_grid.py) 读关卡文件

```python
# 读取 JSON 文件（pacman_grid.py）
def get_json(self, path):
    with open(path) as fp:          # 打开文件
        payload = json.load(fp)     # 解析 JSON → Python 字典
    return payload
    # with 语句结束时自动关闭文件，即使中途出错

# 读取最高分（runner.py）
def initialize_highscore(self):
    with open("levels/stats.json") as fp:
        stats = json.load(fp)
        self.game_state.highscore = stats['highscore']
        self.game_state.mins_played = stats['mins_played']

# 写入 JSON 文件（runner.py）
def update_highscore(self):
    with open("levels/stats.json", 'w') as fp:   # 'w' 表示写入模式
        json.dump(
            {
                "highscore": self.game_state.highscore,
                "mins_played": self.game_state.mins_played
            },
            fp,
            indent=4   # 缩进 4 格，方便人类阅读
        )
```

**小白要点**：
- `json.load(fp)` 把文件内容解析成 Python 的字典/列表。
- `json.dump(data, fp)` 把 Python 的字典/列表写成 JSON 文件。
- `with open(...) as fp:` 是推荐写法，离开 `with` 块自动关文件。
- `'r'` 读取（默认），`'w'` 覆盖写入，`'a'` 追加写入。

## 14. 异常处理 try / raise

**一句话**：`raise` 主动抛出一个错误，`try/except` 捕获错误防止程序崩溃。

**在哪里看**：[src/game/state_management.py](../src/game/state_management.py) 的 setter 校验

```python
# 主动抛出异常（state_management.py）
@direction.setter
def direction(self, value):
    if value not in ["r", "l", "u", "d", ""]:
        raise ValueError("Unknown direction")  # 非法值直接报错
    self.__direction = value

@ghost_mode.setter
def ghost_mode(self, value):
    if value not in ['scatter', 'chase', 'scared']:
        raise ValueError("Only scatter, scared or chase modes are available")
    self._ghost_mode = value
```

```python
# 捕获异常（如果你要扩展代码）
try:
    game_state.direction = "x"  # 非法值
except ValueError as e:
    print(f"方向设置错误：{e}")
    game_state.direction = ""   # 回退到默认值
```

**小白要点**：
- `raise ValueError("消息")` 会立即中断当前函数，向调用者报告错误。
- `try/except` 像一张安全网：`try` 里出错不会崩溃，而是跳到 `except` 处理。
- 本项目里 `raise` 用在「不该发生的错误」上，比如写入了不存在的方向名。

## 15. 列表推导式

**一句话**：用一行代码生成一个新列表，比写 `for` 循环更简洁。

**在哪里看**：[src/sprites/pacman.py](../src/sprites/pacman.py) 的 `load_all_frames` 方法

```python
# 普通写法（多行）
frames = []
for path in PACMAN_PATHS["left"]:
    img = transform.scale(image.load(path).convert_alpha(), PACMAN)
    frames.append(img)

# 列表推导式（一行搞定，pacman.py 实际代码）
def frame_helper(direction):
    width, height = PACMAN
    return [
        transform.scale(image.load(path).convert_alpha(), (width, height))
        for path in PACMAN_PATHS[direction]
    ]
# 读法：「对 PACMAN_PATHS[direction] 里每个 path，做 load+scale，结果收集成列表」
```

```python
# 另一个例子：创建 tiny_matrix（coord_utils.py）
tiny_matrix = [["null"] * num_cols for _ in range(num_rows)]
# 等价于：
tiny_matrix = []
for _ in range(num_rows):
    tiny_matrix.append(["null"] * num_cols)
```

**小白要点**：
- 格式：`[表达式 for 变量 in 可迭代对象]`
- 可以加条件：`[x for x in range(10) if x % 2 == 0]` → `[0, 2, 4, 6, 8]`
- 读法：「对每个 xxx，计算 yyy，收集成列表」。
- 不要嵌套超过两层，否则可读性变差。

## 16. 类型注解 type hint

**一句话**：在参数和返回值后面标注类型，方便阅读和 IDE 检查，但 Python 运行时不强制。

**在哪里看**：[src/sprites/pacman.py](../src/sprites/pacman.py) 和 [src/gui/score_screen.py](../src/gui/score_screen.py)

```python
# 参数类型注解
def __init__(self,
             screen: Surface,           # 这个参数应该是 pygame.Surface 类型
             game_state: GameState,     # 应该是 GameState 类型
             matrix: list[list[str]],   # 应该是字符串的二维列表
             pacman_pos: tuple,         # 应该是元组
             start_pos: tuple):
    ...

# 返回值类型注解
def get_coords_from_idx(...) -> tuple:
    ...

# Union 类型：可以是多种类型之一
from typing import Union
def build_bounding_boxes(self, x: Union[int, float], y: Union[int, float]):
    ...
```

**小白要点**：
- 类型注解是给「人和 IDE」看的，Python 运行时不检查。
- `screen: Surface` 不意味着传其他类型会报错，只是告诉你「应该传 Surface」。
- 好的类型注解让代码更易读，IDE 也能给出更好的补全提示。

## 17. 抽象基类 ABC

**一句话**：`ABC`（Abstract Base Class）让你定义「模板类」，强制子类实现某些方法。

**在哪里看**：[src/sprites/ghosts.py](../src/sprites/ghosts.py)

```python
from abc import abstractmethod, ABC

class Ghost(Sprite, ABC):
    """幽灵基类：不能直接创建 Ghost 对象"""

    @abstractmethod
    def determine_target(self):
        """
        子类必须实现这个方法。
        如果某个子类没实现，创建该子类对象时直接报 TypeError。
        """
        ...

# 正确：Blinky 实现了 determine_target
class Blinky(Ghost):
    def determine_target(self):
        return GHOST_SCATTER_TARGETS[self.name]

# 错误：如果某个子类没实现 determine_target
class MyGhost(Ghost):
    pass  # 没实现抽象方法

# ghost = MyGhost(...)  # 这行会报错！TypeError
```

**小白要点**：
- `ABC` 让类变成「模板」，不能直接创建对象。
- `@abstractmethod` 标记的方法，子类必须重写。
- 好处：四只幽灵都必须有自己的 `determine_target`，漏写了编译器会提醒。
- 这是「契约」：基类规定接口，子类各自实现。

## 18. 单例模式 singleton

**一句话**：确保一个类只有一个对象实例，全局共享。

**在哪里看**：[src/sounds.py](../src/sounds.py)

```python
class SoundManager:
    _instance = None  # 类变量：所有对象共享同一个 _instance

    def __new__(cls, *args, **kwargs):
        # __new__ 在 __init__ 之前调用，负责「是否创建新对象」
        if not cls._instance:
            # 还没有实例，创建第一个
            cls._instance = super(SoundManager, cls).__new__(cls, *args, **kwargs)
        # 已有实例，直接返回那个
        return cls._instance

    def __init__(self):
        # 防止重复初始化
        if not hasattr(self, "_initialized"):
            self._initialized = True
            self._sounds = {}
            self._channels = {}
            pygame.mixer.pre_init()
            pygame.mixer.set_num_channels(64)
```

**使用效果**：

```python
# 在 runner.py 里创建一次
sound_manager = SoundManager()
sound_manager.load_sound("dot", "assets/sounds/pacman_chomp.wav")

# 在 pacman.py 里再创建，得到的是同一个对象
self.sound = SoundManager()  # 不会重新初始化！
self.sound.play_sound("dot")  # 能播放 runner 里加载的音效
```

**小白要点**：
- `__new__` 控制「创建不创建新对象」，`__init__` 控制「怎么初始化」。
- `_instance` 是类变量，所有实例共享。第一次创建后，后续 `SoundManager()` 都返回同一个。
- 为什么需要单例？音效管理器只能有一个，否则多个 mixer 会冲突。

## 19. 策略模式（字典映射函数）

**一句话**：用字典代替一长串 `if/elif`，让代码更简洁、更容易扩展。

**在哪里看**：[src/gui/pacman_grid.py](../src/gui/pacman_grid.py)

```python
class PacmanGrid:
    def __init__(self, screen, game_state):
        # 字典：字符串 → 绘制方法
        self.function_mapper = {
            "void": self.draw_void,
            "wall": self.draw_wall,
            "dot": self.draw_dot,
            "power": self.draw_power,
            "null": self.draw_void,
            "elec": self.draw_elec,
        }

    def draw_level(self):
        for _, row in enumerate(self._matrix):
            for _, col in enumerate(row):
                # 不用 if/elif，直接查字典找到对应的画法
                draw_func = self.function_mapper[col]
                draw_func(x=curr_x, y=curr_y, w=CELL_SIZE[0], h=CELL_SIZE[0])
                curr_x += CELL_SIZE[0]
            ...
```

**如果不用策略模式**（反面教材）：

```python
# 这样写又长又难改
for col in row:
    if col == "void":
        self.draw_void(...)
    elif col == "wall":
        self.draw_wall(...)
    elif col == "dot":
        self.draw_dot(...)
    elif col == "power":
        self.draw_power(...)
    elif col == "elec":
        self.draw_elec(...)
    # 新增一种格子类型？要在这里加一个 elif...
```

**小白要点**：
- 字典的值可以是函数（方法），调用时加括号 `draw_func(...)` 即可。
- 新增格子类型只需：① 写一个新的 `draw_xxx` 方法 ② 在字典里加一行。
- 不用改 `draw_level` 的循环代码，符合「开闭原则」。
