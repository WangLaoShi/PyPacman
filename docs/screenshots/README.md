# PyPacman 游戏截图

本目录包含用于教程网站的游戏运行截图。

## 截图列表

| 文件名 | 描述 | 使用时机 |
|--------|------|----------|
| `01_游戏初始界面.png` | 游戏启动时的初始画面，显示迷宫和初始分数 | 项目概览、架构介绍 |
| `02_游戏进行中_2秒.png` | 游戏开始 2 秒，吃豆人开始移动 | 展示游戏动态 |
| `03_游戏进行中_4秒.png` | 游戏开始 4 秒，幽灵开始活动 | 展示幽灵 AI |
| `04_游戏进行中_6秒.png` | 游戏开始 6 秒，分数增加 | 展示计分系统 |
| `05_游戏进行中_8秒.png` | 游戏开始 8 秒，吃豆人吃到能量豆 | 展示道具系统 |
| `06_游戏结束画面.png` | 游戏结束时的画面 | 展示游戏结束状态 |

## 如何重新生成截图

运行自动截图脚本：

```bash
cd PyPacman
source .venv/bin/activate
python auto_screenshot.py
```

脚本会自动运行游戏 10 秒并在关键时刻保存截图。

## 手动截图

也可以运行游戏并手动截图：

```bash
python capture_screenshots.py
```

在游戏中按 `S` 键保存当前屏幕截图，按 `Q` 键退出。

## 技术说明

- 截图分辨率：560×620 像素（由 `SCREEN_WIDTH` 和 `SCREEN_HEIGHT` 决定）
- 格式：PNG（无损压缩）
- 截图工具：pygame.image.save()
- 自动截图间隔：2 秒
